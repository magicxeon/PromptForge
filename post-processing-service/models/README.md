# Face Landmarker Pilot Model

Development setup downloads the Google Face Landmarker float16/1 task bundle
from https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
to this directory and verifies SHA-256
64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff.
The binary is local-only and not committed. The API reports unavailable if
it is absent or changed. Package and model redistribution/commercial rights
must be verified independently before any production rollout.
