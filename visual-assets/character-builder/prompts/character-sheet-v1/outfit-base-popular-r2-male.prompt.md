# Male Popular Outfit Base R2

Create a new production source sheet matching the clean monochrome fashion
technical line-art style of Character Sheet Outfit Base R1. Use a white
background, faceless adult male mannequins, restrained pale-gray shading and
one front-facing neutral full-body figure per cell.

Output one row of five equal cells, left to right:

1. lightweight chore jacket, plain crew-neck top and straight chinos;
2. relaxed overshirt, fine-knit or plain top and pleated straight trousers;
3. minimal unbranded bomber, plain top and tapered pants;
4. simple denim jacket, plain top and relaxed wide trousers;
5. camp-collar short-sleeve shirt and knee-length tailored shorts.

No labels, text, borders, logos, fixed colors, crop, overlap or extra figures.
Keep each silhouette commercially polished and distinct at card size.
