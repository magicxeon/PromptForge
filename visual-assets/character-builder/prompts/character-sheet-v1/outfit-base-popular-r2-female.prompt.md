# Female Popular Outfit Base R2

Create a new production source sheet matching the clean monochrome fashion
technical line-art style of Character Sheet Outfit Base R1. Use a white
background, faceless adult female mannequins, restrained pale-gray shading and
one front-facing neutral full-body figure per cell.

Output one row of five equal cells, left to right:

1. modest square-neck knit and high-waist straight tailored trousers;
2. relaxed oversized blazer, fitted plain top and tailored shorts;
3. waist-length cardigan and bias-cut midi skirt;
4. simple denim jacket, fitted plain top and high-waist wide trousers;
5. modest sleeveless high-neck knit and softly pleated midi skirt.

No labels, text, borders, logos, fixed colors, crop, overlap or extra figures.
Keep each silhouette opaque, modest, commercially polished and distinct.
