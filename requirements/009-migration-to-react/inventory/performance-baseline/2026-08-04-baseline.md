## Runtime Instrumentation

- API requests under `/api/` now emit bounded duration samples through
  `PerformanceTelemetry`.
- Slow API logs contain method, route, status, duration and request ID only.
- Generation jobs expose queue wait, Reference Processing, provider, output
  persistence and total timing boundaries through safe status diagnostics.
- Samples are in-memory and bounded; prompts, Base64 payloads and private
  references are not retained.
- Generation, Comparison, Fashion and Template preparation polling intervals
  and terminal rules are owned by `web/src/lib/api/pollingPolicy.ts`.

## Remaining Measurement Gap

API P95, browser interaction timing, memory high-water marks and representative
Fashion bulk-load measurements require the production-like seeded dataset and
load harness defined by Requirement 017. Provider duration must remain separate
from application latency in those measurements.
