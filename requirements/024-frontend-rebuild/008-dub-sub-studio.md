# Dub & Sub Studio — โปรเจกต์ซับและพากย์เสียง

เทคที่เลือกบนไทม์ไลน์แล้วสามารถส่งออกได้เต็มเสียงเมื่อจุดเริ่มและจบอยู่ภายในคลิป แม้เลื่อนเทคจนเสียงเกินช่วงซับ หรือเทคเดิมไม่มีประวัติยืนยันเวลาเกิน ให้แจ้งเตือนโดยยังเปิดปุ่มส่งออก

ส่งออก WAV และ MP4 ที่ใช้เสียงพากย์ได้เมื่อเทคซ้อนกัน หน้าส่งออกแจ้งเวลาที่เริ่มซ้อนครั้งแรกตามภาษาและแทร็กที่เปิดอยู่ ผู้ใช้กดส่งออกได้ทันที ตัวมิกซ์รักษาตำแหน่งและเสียงท้ายของทุกเทคแม้ซ้อนข้ามกลุ่มประมวลผล

การพากย์ตามจังหวะต้นฉบับทั้งรายประโยคและทั้งเรื่องให้เผื่อท้ายเสียงพูดช่วงสุดท้ายสูงสุด 500 มิลลิวินาที ตั้งค่าได้ที่ `timedDialogue.alignment.speechTailMs` ใน `server/config/dub-scene-transcription.json` โดยคงจุดเริ่มและช่วงพักเดิม จำกัดเวลาเผื่อตามคิวถัดไปและจุดจบวิดีโอ เทคที่จบตามเวลาเดิมยังใช้ได้ และเทคที่วางภายในเวลาเผื่อสามารถส่งออกเต็มความยาวได้

เปิดใช้งานที่ `/dub-sub` บน frontend ใหม่แล้ว ผลตรวจด้วยคลิปทดสอบและรายการที่ต้องประเมินด้วยคลิปละครจริงอยู่ใน [คู่มือใช้งาน](011-dub-sub-operations.md) ดู [แบบหน้าจอและเกณฑ์ตรวจรับ](010-dub-sub-editor-design.md) และ [คู่มือ Seed Audio](009-seed-audio-manual.md)

## 1. ทางเข้าและขอบเขต

### ถอดซับเพิ่มเฉพาะช่วงที่ขาด

เมื่อเปิดหน้าถอดใหม่ในโปรเจกต์ที่มีบท ให้ตรวจประโยคที่ขาดบทพากย์หรือเสียงพากย์ของภาษาที่เลือกเป็นอันดับแรก ใช้เกณฑ์เดียวกับหน้าพากย์ทั้งเรื่อง แสดงเวลา ข้อความ และสิ่งที่ต้องเติมสำหรับแต่ละประโยค ให้เปิดแก้ประโยคนั้นหรือแปลข้อความเดิมโดยตรง การตรวจนี้ไม่ส่งเสียงให้ Gemini ผู้ใช้ยังเลือกถอดทั้งคลิปหรือระบุช่วงเวลาที่ได้ยินบทตกหล่นเองได้

เมื่อมีบทอยู่แล้ว ให้ผู้ใช้เลือกถอดทั้งคลิปหรือเลือกช่องว่างบนไทม์ไลน์หนึ่งช่วงในหน้าต่าง Gemini แสดงเวลาเริ่มและสิ้นสุดก่อนส่ง รวมช่องว่างก่อนบทแรกและหลังบทสุดท้าย ช่องว่างหมายถึงช่วงที่ยังไม่มีซับ ซึ่งอาจเป็นช่วงเงียบได้

1. ใช้โปรเจกต์ฉบับที่บันทึกล่าสุด ตรวจสิทธิ์และขอบเขตเวลาอีกครั้งที่เซิร์ฟเวอร์ ส่งเฉพาะเสียงภายในช่วงที่เลือก พร้อมบริบทเดิมของเรื่อง การส่งซ้ำใช้ผลที่ตรงกับโปรเจกต์ เวอร์ชัน ภาษา และช่วงเวลาเดียวกัน
2. แสดงเฉพาะซับที่พบในช่วงนั้นพร้อมเวลาจริงของคลิป ให้แก้ชื่อผู้พูดก่อนยืนยัน ถ้าไม่พบเสียงพูดให้แสดงผลตามจริง ผู้ใช้ยกเลิกได้
3. เมื่อยืนยัน ให้เพิ่มซับตามลำดับเวลา เก็บบทเดิมทุกภาษา เทคเสียง และการจับคู่ผู้พูด ถ้าเวอร์ชันเปลี่ยนหรือช่วงนั้นมีซับแล้ว ให้อ่านข้อมูลใหม่ก่อนนำผลไปใช้

ตรวจรับด้วยคลิปที่มีบทเดิมทั้งก่อนและหลังช่องว่าง ตรวจขนาดเสียงที่ส่ง เวลาของซับใหม่ การแยกผลระหว่างช่วง การยกเลิกและการคงเทคเดิมหลังบันทึก

### เสียงฉากตอนส่งออก

เมื่อเลือกเก็บเสียงฉาก หน้าเว็บต้องตรวจผลยืนยัน BandIt v2 จากการเรนเดอร์ก่อนเสนอไฟล์ให้ดาวน์โหลด งานที่ API รุ่นก่อนเคยผสมเสียงต้นฉบับทั้งแทร็กใช้แทนผลแยกเสียงไม่ได้

ระหว่างเตรียมไฟล์หรือเรนเดอร์เฟรม ให้แสดงคลื่นเสียงพร้อมข้อความสถานะในหน้าต่างส่งออกและกันการส่งซ้ำ คลื่นหยุดเมื่องานสำเร็จหรือผิดพลาด เมื่อพร้อมให้คงหน้าต่างไว้พร้อมปุ่มดาวน์โหลดไฟล์จากโปรเจกต์ เมื่อผิดพลาดให้แสดงสาเหตุและลองใหม่ด้วยค่าที่เลือกไว้ได้

หน้าส่งออกเรียงตามสิ่งที่จะได้ในไฟล์ เลือกชนิดไฟล์ก่อน สำหรับ MP4 เลือกเสียงต้นฉบับหรือเทคจากไทม์ไลน์ เมื่อใช้เทคให้เลือกภาษาพากย์และเสียงฉากในกลุ่มเดียวกัน กลุ่มซับแยกภาษาที่ส่งออก การฝังซับ และพรีวิวเฟรม สำหรับ WAV แสดงตัวเลือกเสียง ส่วน SRT/VTT แสดงภาษาซับ ตรวจการสลับชนิดไฟล์และการจัดวางบนมือถือ แท็บเล็ต และเดสก์ท็อป

เมื่อส่งออก MP4 พร้อมพากย์หรือ WAV พากย์ ให้เลือกเก็บเสียงฉากเป็นค่าเริ่มต้น ระบบใช้ BandIt v2 แยกดนตรีและเอฟเฟกต์จากต้นฉบับ ผสมกับเทคตามเวลาและระดับเสียงพากย์ที่เลือก ปิดตัวเลือกเพื่อรับเฉพาะเสียงพากย์ การส่งออกซับหรือวิดีโอต้นฉบับข้ามการแยกเสียง เก็บเสียงฉากที่แยกสำเร็จในโฟลเดอร์สื่อของโปรเจกต์เพื่อใช้ซ้ำกับเทคใหม่ ตรวจด้วยคลิปและเทคเดิมผ่านตัวเรนเดอร์ส่งออก

เมนูหลักแสดง Playground และ Dub & Sub Studio เรียงข้างโลโก้ เมื่อจอกว้างไม่เกิน 700px ให้รวมลิงก์ไว้ในเมนูแฮมเบอร์เกอร์ เน้นพื้นที่ทำงานปัจจุบันตาม URL รวมหน้าย่อยและการใช้ปุ่มย้อนกลับของเบราว์เซอร์ ผู้ใช้ปิดรายการด้วยการเลือกเมนู กด Escape หรือคลิกด้านนอกได้

เมื่อเข้า Dub & Sub Studio ให้เปิด **โปรเจกต์** ผู้ใช้เลือกเสียงและเทคเดิมได้จากประโยคใน Editor ผู้ใช้เตรียมเสียงที่หน้า **ตั้งค่า → เสียงพากย์** แล้วเลือกเสียงให้แต่ละตัวละครใน modal **ตรวจผู้พูดและเลือกเสียงพากย์** ที่เปิดหลังแยกผู้พูด ดู [ข้อกำหนดและเกณฑ์ตรวจรับ](012-dubbing-voices.md)

กรณีใช้งานหลัก: นำเข้าละครจีน → ถอดบทพร้อมเวลา → ตรวจคำแปลไทย → จับคู่ผู้พูดกับเสียงตัวละคร → ฟังเสียงพากย์พร้อมภาพ → ส่งออกซับ เสียง หรือวิดีโอ ผู้ทำซับอย่างเดียวส่งออกได้ตั้งแต่ตรวจคำแปลเสร็จ

### บทเสียง / Audio Scripts

ผู้ใช้เลือกอารมณ์ “สนุกสนาน” ต่อประโยคได้ โดยส่งคำกำกับ `cheerful` ไปยัง Seed Audio

ระยะเวลาพูดเป้าหมายกำหนดแยกต่อประโยคได้ทั้งการสร้างรายแถวและทั้งชุด ค่า 0 ใช้จังหวะเดิม ค่าบวกรับวินาทีทศนิยมถึงมิลลิวินาที การเปลี่ยนเวลาต้องทบทวนเทคเดิม ช่วงเงียบหลังประโยคกำหนดแยกต่างหาก

ใน Dub & Sub Studio ให้เรียงเมนู **โปรเจกต์ · บทเสียง · ตั้งค่าเสียงพากย์** ผู้ตัดต่อเข้าหน้าบทเสียงได้โดยตรง ตั้งชื่อชุดบท เลือกภาษาพูด และกลับมาเปิดร่างหรือเทคที่บันทึกไว้ภายหลังได้ งานนี้เริ่มจากข้อความและจบที่ไฟล์ WAV สำหรับนำไปวางในคลิปภายหลัง

| ขั้นตอน | สิ่งที่ผู้ใช้ทำและผลที่ต้องได้ |
|---|---|
| 1. จัดตัวละคร | ตั้งชื่อตัวละครหรือผู้บรรยายแล้วจับคู่กับเสียงที่บันทึกไว้ในหน้าตั้งค่าเสียงพากย์ ฟังตัวอย่างก่อนเลือก การใช้ตัวละครเดิมในหลายแถวจะใช้เสียงประจำตัวเดิม |
| 2. เขียนทีละประโยค | หนึ่งแถวมีผู้พูดหนึ่งคนและบทพูดหนึ่งช่วง เพิ่ม ลบ และสลับลำดับแถวได้ บทบรรยายใช้ผู้พูดคนเดียวตลอดชุด บทสนทนาเลือกสลับตัวละครตามแถวได้ |
| 3. กำกับการพูด | ให้เห็นตัวละคร บทพูด อารมณ์ และความเร็วในแถวเดียว เก็บความเข้มของอารมณ์ ระดับเสียงสูงต่ำ ความดัง และคำกำกับอิสระไว้ในส่วนขยาย เช่น “เริ่มลังเล แล้วค่อยมั่นใจ” กำหนดช่วงเงียบหลังแถวได้สำหรับจังหวะรับส่งบท |
| 4. สร้างและฟัง | กดสร้างเฉพาะแถวเพื่อทดลอง หรือสร้างทั้งชุดจากแถวที่ยังขาดเทคปัจจุบัน ใช้เทคที่ผู้ใช้เลือกแล้วซ้ำได้ ฟังรายแถวหรือฟังเรียงทั้งชุด หากแก้ประโยคหรือคำกำกับ ให้ระบุแถวที่ต้องสร้างใหม่และเก็บเทคก่อนหน้าไว้ฟังเทียบ |
| 5. ส่งออก | ดาวน์โหลด WAV เฉพาะแถวหรือ WAV รวมหนึ่งไฟล์จากเทคที่เลือกตามลำดับและช่วงเงียบที่กำหนด ใช้ความยาวจริงของเสียงแต่ละแถว แจ้งแถวที่ยังขาดเทคหรือรอทบทวนก่อนส่งออกทั้งชุด |

ขีดจำกัดของคำกำกับแถวบทเสียงนับแยกตามช่องตาม configuration จึงใช้คำกำกับได้ครบพร้อมเลือกอารมณ์และวิธีพูด พรอมป์ที่ประกอบแล้วต้องอยู่ในขีดจำกัดของโมเดล

**อารมณ์สำหรับสร้างเทครายประโยค** ในหน้าบทเสียงและแผงกำกับเสียง ให้เลือก “ตื่นเต้น” (excited), “ตกใจ/สะดุ้ง” (startled), “กลัว” (afraid), “กังวล” (anxious) และ “โล่งใจ” (relieved) เพิ่มจากชุดเดิม โดยคง “ประหลาดใจ” (surprised) สำหรับปฏิกิริยาเมื่อพบสิ่งเหนือความคาดหมาย ใช้รายการจาก configuration กลางเดียวกันทั้งสองหน้า แสดงชื่อไทยและอังกฤษตามภาษา UI และส่งคำกำกับการแสดงภาษาอังกฤษของอารมณ์ที่เลือกไปกับการสร้างเทค พร้อมระดับความเข้มเดิม

**การส่งไป Seed Audio** ใช้ preset และบริการสร้างเสียงเดิมที่กำหนดรุ่น `seed-audio-1.0-multilingual` ใน [แค็ตตาล็อกโมเดล](../../server/config/voice-studio/models.v1.json) ผูกเสียงต้นแบบกับผู้พูดแต่ละแถว แยกบทที่ต้องพูดตามข้อความออกจากคำกำกับภาษาอังกฤษ ส่งอารมณ์ ความเข้ม และวิธีแสดงผ่าน `text_prompt` ส่วนความเร็ว `speech_rate` ระดับเสียงสูงต่ำ `pitch_rate` และความดัง `loudness_rate` เป็นตัวเลือกของ `audio_config` ตามตัวอย่าง API รุ่น 1.0 ก่อนเปิดใช้แต่ละค่าให้ตรวจว่า adapter ส่งค่านั้นจริงและรุ่น Multilingual ที่ตั้งค่าไว้รองรับ ช่วงค่าและตัวเลือกอ่านจาก configuration ตามความสามารถของโมเดล ช่วงเงียบระหว่างแถวกำหนดตอนประกอบ WAV เพื่อให้แก้จังหวะได้โดยใช้เทคเดิม [คู่มือระบบ](009-seed-audio-manual.md) · [BytePlus Audio 1.0](https://docs.byteplus.com/en/docs/byteplusvoice/seedaudio-01?lang=en)

**เกณฑ์ทดลองรุ่นแรก** สร้างสามแถว “ผู้บรรยาย → คุณชาย → เสี่ยวเหมย” ให้แถวสุดท้ายตอบด้วยความประหลาดใจ ทดลองสร้างและฟังเฉพาะแถวนั้น แล้วกดสร้างทั้งชุด ระบบต้องใช้เทคที่เลือกของแถวสุดท้าย แสดงสถานะคลื่นเสียงและข้อผิดพลาดแยกรายแถว ลองใหม่เฉพาะแถวที่ล้มเหลวได้ การเปิดชุดเดิมต้องคืนลำดับและเทคที่เลือก ไฟล์รวมต้องเปิดฟังได้ครบทั้งสามแถวตามลำดับและมีความยาวเท่ากับผลรวมเทคกับช่วงเงียบ การฟังซ้ำ เรียงแถว หรือส่งออกใช้ไฟล์เสียงเดิม

#### ลำดับพัฒนาและเกณฑ์ UX/UI หลังทบทวน

ปุ่มฟังตัวอย่างเสียงในแถวและหน้าต่างเพิ่มผู้พูดใช้ปุ่มเดียวสลับเล่นและหยุด เมื่อเสียงจบให้คืนปุ่มเล่น เลือกฟังตัวอย่างถัดไปให้หยุดเสียงก่อนหน้า โดยไม่แสดงแถบเครื่องเล่น

ในแต่ละประโยค ให้ผู้ใช้เห็นผู้พูด ช่องเขียนบทที่ใหญ่ที่สุด และปุ่มสร้างเทคในพื้นที่หลักเดียวกัน ใต้พื้นที่เขียนเป็นแผง “กำกับการอ่าน” ที่แยกด้วยพื้นสีและหัวข้อ แสดงอารมณ์กับความเร็วก่อน ส่วนตัวเลือกละเอียดพับไว้ เปิดแผงแล้วปุ่มสร้างเทคต้องอยู่ที่เดิม บนจอแคบให้ตัวเลือกเรียงตามลำดับอ่านและใช้งานด้วยแป้นพิมพ์ได้

1. วางแท็บ **บทเสียง** ระหว่างโปรเจกต์และตั้งค่าเสียงพากย์ เข้าจากรายการชุดบท สร้างชุดด้วยชื่อและภาษา เริ่มพิมพ์จากแถวแรกได้ทันที เก็บชุดบทในเอกสาร Voice Studio ของเจ้าของ แยกชนิดจากเอกสารที่ Editor ใช้กำกับซับ
2. ให้ชื่อผู้พูดอยู่ติดบท เลือกตัวละครเดิมซ้ำได้ ฟังเสียงประจำตัวได้ก่อนสร้าง แสดงอารมณ์และความเร็วตรงแถว เปิดส่วนกำกับเพิ่มเมื่อต้องการ สีขอบและป้ายกำกับแยกแถวที่กำลังแก้ สีเขียวกับคำว่า “เลือกแล้ว” ระบุเทคที่ใช้งาน สีอำพันบอกว่าบทเปลี่ยน สีแดงพร้อมเหตุผลและปุ่มลองใหม่ระบุข้อผิดพลาด ทุกสถานะต้องอ่านได้ทั้งจากข้อความและแป้นพิมพ์
3. แยกคำสั่งของแถวจากแถบของทั้งชุด แสดงจำนวนแถวที่ต้องสร้างก่อนกด การสร้างทั้งชุดไล่ทีละแถวและรักษาเทคที่ใช้ได้อยู่ เมื่อแก้บท/ผู้พูด/คำกำกับให้ฟังเทคเดิมเทียบหรือยืนยันใช้เทคนั้นได้ การย้ายแถวและแก้ช่องว่างไม่ทำให้เทคหมดอายุ
4. ใช้บริการเสียงและสิทธิ์เดิม การฟังและส่งออกต้องอ่านเทคส่วนตัวของผู้ใช้ WAV รวมประกอบจากเสียงที่เลือกกับช่วงเงียบ เมื่อมีแถวขาดเสียงต้องบอกว่าแถวใด รองรับจอมือถือด้วยการเรียงฟิลด์ลงด้านล่าง ให้ปุ่มมีชื่อและสถานะที่แยกได้ในภาษาไทยและอังกฤษ ตรวจการเปิดร่างใหม่ การสร้างซ้ำ และการแก้ไขข้ามแท็บด้วยข้อมูลจำลอง

**ผลการตรวจบทเสียง** เปิดหน้า `/dub-sub/audio-scripts` บนเว็บพัฒนาได้แล้ว ทดสอบในเบราว์เซอร์ที่ความกว้าง 390, 820 และ 1440 พิกเซลด้วยผู้พูดสามคน สร้างแยกและต่อทั้งชุด เรียงประโยคใหม่ ฟังรายแถว เปิดบทเดิม และกู้สถานะงานจากเซสชันใหม่ ตรวจข้อมูล PCM ใน WAV ทั้งลำดับตัวอย่างเสียงและความยาวช่วงเงียบ [ชุดตรวจเบราว์เซอร์](../../web-next/test/audio-scripts-check.mjs)

ชุดทดสอบ backend ผ่าน 42 กรณี ครอบคลุมสิทธิ์เจ้าของ การเลือกเทคหลังเปลี่ยนเสียงประจำตัว การใช้ใบเสนอราคาเดิม และคำกำกับภาษาอังกฤษ ใน payload รุ่น Multilingual จากหน้า Dola มีฟิลด์ความเร็ว ความดัง และระดับเสียงสูงต่ำเป็นศูนย์ทั้งหมด การทดสอบ adapter ยืนยันว่าส่งค่าที่แก้แล้วตาม configuration ได้ ส่วนผลเมื่อใช้ค่าที่ต่างจากศูนย์บนบริการจริงยังรอทดสอบ [การทดสอบเสียง](../../test/voiceSpeech.test.js) · [การทดสอบบทและเทค](../../test/voiceStudio.test.js)

## 2. Dashboard และ Create

**ข้อมูลภาษาและบริบทของโปรเจกต์** ตอนสร้างให้แสดงภาษาต้นฉบับและภาษาแปลสูงสุดสองภาษาก่อนส่วนเลือกไฟล์ ตามด้วยข้อมูลเสริมสองช่อง คือ “ยุคสมัยและแนวภาษา” และ “เรื่องย่อหรือบริบทของฉาก” ผู้ใช้พิมพ์ได้เองทั้งไทยและอังกฤษ เว้นว่างได้ และแก้ชื่อกับบริบทภายหลังผ่านหน้าต่าง “แก้ไขโปรเจกต์” ข้อมูลทั้งสองเป็นส่วนหนึ่งของ revision และเป็นบริบทสำหรับการถอดและแปลทั้งฉากด้วย Gemini

- มุมมองรายการและการ์ดใช้ชุดโปรเจกต์เดียวกัน เรียงตามเวลาที่แก้ล่าสุด แสดงภาพปก ชื่อ ระยะวิดีโอ ภาษาต้นทาง → ปลายทาง วันที่ สถานะ และการกระทำหลักตามภาพอ้างอิง แบ่งหน้าโดย cursor
- Create เปิดแบบฟอร์มสั้นสำหรับอัปโหลดหรือเลือกวิดีโอที่ผู้ใช้มีสิทธิ์ ตั้งชื่อ ตรวจตัวอย่างและระยะเวลา เลือกภาษาต้นทางหรือ Auto และภาษาปลายทาง จากนั้นเลือกเริ่มถอดเสียงหรือเปิดแก้ซับเอง
- แสดงสถานะจากงานจริง ได้แก่ นำเข้า ถอดเสียง แปล พร้อมแก้ไข กำลังส่งออก และส่งออกสำเร็จ เมื่อประมวลผลล้มเหลวระบุขั้นที่ล้มเหลวและลองใหม่เฉพาะขั้นได้ ปุ่ม Edit เปิดงานล่าสุด ปุ่ม Download แสดงเมื่อมีไฟล์ส่งออกสำเร็จ เมนูเพิ่มเติมรวมเปลี่ยนชื่อและเก็บเข้าคลัง
- Ready หมายถึงพร้อมแก้บท ส่วน Complete หมายถึงมีผลส่งออกของ revision ปัจจุบัน เมื่อแก้งานหลังส่งออกให้ระบุว่าไฟล์เดิมเป็นเวอร์ชันก่อนหน้า

## 3. Editor สำหรับกำกับบทกับภาพ

### การแก้ซับและจัดการโปรเจกต์จากหน้าที่กำลังใช้

- Projects ใช้ปุ่ม ⋯ ต่อโปรเจกต์ทั้งมุมมองรายการและการ์ด มีแก้ไข เก็บถาวรหรือกู้คืน และลบถาวร เมื่อเลือกลบให้แสดงชื่อและขอบเขตไฟล์ กดยกเลิกได้ การยืนยันลบโปรเจกต์และไฟล์ส่วนตัวของโปรเจกต์ต้องตรวจเจ้าของ revision และงานที่ยังทำอยู่ ไฟล์ที่แชร์จากคลังมีอายุแยกจากโปรเจกต์
- ผู้ใช้แก้ต้นฉบับและคำแปลในแถวบทด้านซ้ายโดยตรง ทีละภาษา ใช้การบันทึกเดิม คงการเลือกข้อความ การพิมพ์ไทย/จีน การล็อกแทร็ก และการเลือกช่วงจากเวลา
- ลากตัวซับบนภาพขึ้นหรือลงเพื่อปรับความสูงของแทร็กนั้น ดูผลขณะลาก บันทึกตอนปล่อย คงพิกัดแนวนอนเดิม รองรับคีย์บอร์ด ยกเลิกการลาก และ Undo นำตัวปรับแกน X/Y ออกจากรูปแบบซับ
- รวบรวมการถอดเสียง อ่านซับฝัง และนำเข้าไว้กับแทร็กต้นฉบับ การแปลใหม่ทั้งเรื่องระบุภาษาเป้าหมายและยืนยันก่อนทับคำแปลของภาษานั้น การแปลประโยค แบ่ง รวม และลบอยู่กับช่วงที่เลือก ใช้เสียงจาก Voice Studio สำหรับพากย์ประโยค ปุ่มพากย์อัตโนมัติทั้งเรื่องและการจับคู่เสียงอัตโนมัติกำหนดไว้ใน [แผนเสียงพากย์](012-dubbing-voices.md)
- ในเครื่องมือแปลของภาษาเป้าหมาย ปุ่ม “แปลทุกประโยค” ใช้ได้ทันทีที่มีข้อความต้นฉบับ ยืนยันเฉพาะเมื่อจะแทนที่คำแปลเดิม หากแทร็กถูกล็อก ให้ปลดล็อกได้จากเมนูเดียวกันด้วยคำสั่งแยก ตรวจเส้นทางปลดล็อก การแปลครั้งแรก และการยกเลิกหรือยืนยันแปลทับด้วย `web-next/test/dub-editor-check.mjs` ผ่านแล้ว ขอบเขตสถาปัตยกรรมเดิม (architecture map unchanged)

รางเลื่อนเวลาใต้ภาพต้องคงตำแหน่งและความกว้างระหว่างเล่น หยุด และเปลี่ยนค่ามิลลิวินาที ตรวจช่วง 7.3–13.2 วินาทีด้วย Chromium บน Windows ก่อนแก้ขอบรางขยับ 20.27 พิกเซล หลังแก้ขอบรางคงที่ตลอด 357 เฟรม และหัวเลื่อนไม่ถอยหลังระหว่างเล่นตามปกติ

โหมดพอดีจอต้องคงความกว้างของไทม์ไลน์จนถึงเฟรมสุดท้าย โดยเส้นเวลาและคลิปที่ขอบไม่สร้างพื้นที่เลื่อนเพิ่ม ตรวจด้วย Chromium ที่ใช้ scrollbar แบบ Windows ทั้งการไปท้ายวิดีโอ ซูม 4× เลื่อนสุด และกลับพอดีจอ ที่ 1366×768 และ 1366×620 พบการสลับขนาดแถบ 0 ครั้งใน 45 เฟรมหลังแก้

ระหว่างเล่นในโหมดพอดีจอ การเปลี่ยนประโยคต้องคงตำแหน่งแนวนอนของไม้บรรทัด คลื่นเสียง และบล็อกซับ ให้ไฮไลต์เปลี่ยนตามเวลาและให้เส้นเล่นเดินตามวิดีโอ ตรวจการเล่นจริงช่วง 13.094–19.501 วินาทีบน Chromium/Windows จำนวน 387 เฟรม พบตำแหน่งเลื่อนแนวนอนเป็นศูนย์ตลอด คลื่นเสียงและบล็อกซับอยู่กับที่ และเส้นเล่นไม่ถอยหลัง เพิ่มการตรวจช่วงนี้ใน `web-next/test/dub-timeline-check.mjs` ภายในขอบเขตเดิมของ Editor (architecture map unchanged)

เมื่อเปิด Editor ให้กันพื้นที่ให้ไม้บรรทัด คลื่นเสียง และแถวซับด้านล่างตั้งแต่เฟรมแรก ที่จอ 1366×768 ต้องเห็นแทร็กต้นฉบับและภาษาแปลแรกพร้อมวิดีโอโดยไม่ต้องเลื่อนหน้า แทร็กที่เกินให้เลื่อนภายในไทม์ไลน์ บทและ Tracks เลื่อนในแผงของตนเอง จอแคบเปิด Tracks ทับพื้นที่ทำงานได้ ช่องปรับเวลาแบบละเอียดและวิธีใช้คีย์บอร์ดเปิดเมื่อต้องการ แถวบทที่เวลาเริ่ม ≤ playhead < เวลาจบต้องไฮไลต์ทั้งแถวเมื่อเล่นหรือ seek และเลื่อนตามเป็นค่าเริ่มต้น เมื่ออยู่ในช่วงเงียบให้หยุดไฮไลต์ การติดตามเวลาต้องคงโฟกัสและประโยคที่กำลังพิมพ์

| พื้นที่ | พฤติกรรมที่ต้องได้ |
|---|---|
| หัวหน้า | กลับ Projects, เปลี่ยนชื่อ, Save พร้อมสถานะบันทึก, Export เมื่อออกจากหน้าขณะมีงานค้างให้เลือกบันทึกหรือกลับมาแก้ |
| บทด้านซ้าย | ค้นข้อความต้นฉบับหรือคำแปล แสดงเวลาเริ่ม–จบ ผู้พูด และสองภาษาคู่กัน เลือกแถวแล้ว seek วิดีโอและเลือกคลิปบน timeline แก้ข้อความ เพิ่ม แบ่ง รวม หรือลบช่วงพร้อม Undo/Redo |
| ภาพกลาง | เล่นวิดีโอตามสัดส่วน แสดงซับของแทร็กที่เปิด ณ เวลาเดียวกับเสียง Play/Pause, ก่อนหน้า/ถัดไปตามประโยค, timecode, volume และ fullscreen เลือกวนฟังประโยคเดียวเพื่อกำกับการอ่าน |
| Tracks ด้านขวา | จัดการ Captions, Transcription, Translation และเสียงพากย์ เพิ่ม caption หรือภาษาแปล เปิด/ซ่อนซับ ล็อกการแก้ไข เลือกแทร็กเสียงเพื่อ mute/solo หรือปรับระดับเสียง เลือกประโยคแล้วคงเครื่องมือที่กำลังใช้ เปิดรายละเอียดเสียงเมื่อผู้ใช้เลือก “กำกับเสียง” |
| Timeline ด้านล่าง | ไม้บรรทัดเวลา waveform ต้นฉบับ บล็อกซับแยกภาษา และคลิปเทคตามตัวละคร ใช้ playhead เดียวกับภาพและรายการบท ลากย้าย/ปรับขอบช่วง ซูมเวลา เลื่อนแนวนอน ดับเบิลคลิกช่องว่างเพื่อเพิ่มซับ มีช่องเวลาให้แก้ด้วยคีย์บอร์ด |

คลิกช่วงเวลาใด ให้เห็นแถวนั้น แทร็กนั้น และภาพในเวลาเดียวกัน เมื่อเล่นต่อ ให้เน้นประโยคที่กำลังพูดโดยรักษาตำแหน่งที่กำลังพิมพ์อยู่ จอเล็กให้คงภาพและ transport แล้วสลับแผง บท / Tracks / Timeline จอแท็บเล็ตพับแผงขวาได้ รองรับ UI ไทยและอังกฤษแยกจากภาษาของสื่อ คืน focus หลังปิดแผง และคง selection เมื่อบันทึก

## 4. ถอด แปล และพากย์ทับ

1. แยกเสียงจากสื่อที่นำเข้า เรียก ASR ผ่าน server ใช้ผลเวลาเป็นช่วงต้นฉบับ เก็บเวลาเป็นจำนวนเต็มมิลลิวินาที หากขาด timestamp ให้ระบุช่วงที่ต้องจัดเวลาเอง ผู้ใช้เพิ่มแถวเองได้ หากระบบให้ speaker labels ให้ผู้ใช้รวม/แยก/แก้ชื่อได้เสมอ
2. การแปลสร้างชั้นข้อความตามภาษา ผูกกับ cue ID เดิม ผู้ใช้แก้บทพากย์ให้อ่านธรรมชาติแยกจากคำซับได้ การถอดหรือแปลซ้ำต้องให้ตรวจการแทนที่ข้อความที่แก้มือ รองรับ retry รายช่วง
3. จับคู่ผู้พูดกับ character และเสียงจาก Voice Studio ครั้งเดียวต่อโปรเจกต์ เลือก override เฉพาะประโยคได้ แก้บท โทน และจังหวะตามความสามารถโมเดล กด “สร้างเทค” ผ่านขั้นตอน quote เดิม แล้วกด “ฟังเทค” เพื่อเล่นเทคที่มีพร้อมภาพ การฟังซ้ำใช้ไฟล์เดิม เทคทดลองเข้าสู่คลังเสียงเมื่อกด “เก็บเข้าคลัง”
4. เลือกใช้เทคแล้ววางคลิปอัตโนมัติที่เวลาเริ่มของ cue บนแทร็กตัวละคร วัดความยาวไฟล์จริง หากเสียงยาวเกินให้แสดงเวลาเกิน ฟังช่วงชน แก้คำ สร้างเทคใหม่ หรือขยับช่วงด้วยตนเอง เก็บเทคเดิมไว้จนกว่าจะเลือกแทน การเปลี่ยนเสียงของตัวละครระบุเทคที่ต้องทบทวน

**ให้พูดจนจบเมื่อบทยาวเกินคิว** ผู้ใช้เปิดตัวเลือกนี้เองเป็นรายประโยคเพื่อให้เสียงเริ่มตรงต้นคิวและพูดจนจบตามความยาวจริง ค่าเริ่มต้นยังยึดความยาวคิวเดิม ทั้งการประเมินเวลาและการพากย์ทั้งเรื่องต้องเคารพตัวเลือกของผู้ใช้ หากมีเทคเสียงเต็มอยู่แล้ว ให้เลือกใช้เทคนั้นต่อได้ผ่านการยืนยันเวลาเกินคิวเดิม

ในโหมดนี้ให้กรอกเวลาเป้าหมายของเทคเป็นวินาทีได้ ค่าเริ่มต้น 0 หมายถึงไม่ระบุเวลา ค่าบวกใช้แทนเวลาเป้าหมายสำหรับสร้างเสียง โดยคงเวลาเริ่มและจบของคิวบนไทม์ไลน์เดิม

**รอปรับ UI ของแผง “กำกับเสียง” รายประโยคใน Editor**

- แบ่งแผงตามลำดับใช้งานเป็น **บทที่จะอ่าน** (ช่องบทและปุ่มให้ Luna ช่วยย่อ), **เสียงและการแสดง** (เลือกเสียงพากย์และพับรายละเอียดอารมณ์/วิธีพูดได้) และ **สร้างและฟังเทค** ใช้หัวข้อ ช่องไฟ และเส้นแบ่งให้เห็นขอบเขตแม้บนแผงแคบ
- ให้ “สร้างเทค” เป็นปุ่มหลัก ระหว่างสร้างให้แสดงคลื่นเสียง ข้อความสถานะ และปุ่ม “ตรวจสถานะ” อยู่ด้วยกันในส่วนเทค
- วาง “ใช้เป็นเสียงหลักของตัวละครนี้” เป็นคำสั่งรองใกล้ตัวเลือกเสียง เพื่อให้เห็นชัดว่ามีผลกับตัวละคร ส่วนการสร้างเทคใช้กับประโยคที่เลือก
5. ฟังเสียงต้นฉบับและพากย์พร้อมภาพ เลือกระดับเสียงต้นฉบับหรือปิดได้ สำหรับต้นฉบับที่ผสมบทพูดและเพลงในไฟล์เดียว การลดระดับมีผลกับทั้งไฟล์ แสดงแทร็กเพลงแยกเมื่อมีไฟล์แยกจริง
   - ที่หัวแทร็กเสียงบน Timeline ทั้งเสียงต้นฉบับและเสียงพากย์รายตัวละคร ให้กดได้ทั้ง checkbox และชื่อแทร็ก ติ๊กเพื่อฟัง เอาติ๊กออกเพื่อปิดเสียงเฉพาะแทร็กนั้นระหว่างดูตัวอย่าง และเมื่อเปิดอีกครั้งให้กลับไปใช้ระดับเสียงเดิม
   - เกณฑ์ตรวจรับ: ระหว่างเล่นวิดีโอ ผู้ใช้เอาติ๊ก “เสียงต้นฉบับ” ออกเพียงครั้งเดียวแล้วได้ยินเฉพาะแทร็กพากย์ไทยที่เปิดอยู่ วิดีโอเล่นต่อจากตำแหน่งเดิม และซับแสดงตามค่าที่เลือกไว้
6. Export ให้เลือกภาษากับผลลัพธ์ ได้แก่ ซับ SRT/VTT, เสียงพากย์ผสม หรือวิดีโอพร้อมเสียงและตัวเลือกฝังซับ ตรวจ cue นอกความยาววิดีโอ แถวขาดเทค และเสียงซ้อนก่อนส่งออก ให้ผู้ใช้เห็นช่วงที่ได้รับผล สร้างไฟล์ตาม revision ที่เลือก ดาวน์โหลดซ้ำจาก Dashboard ได้

## 5. ข้อมูลและบริการ

### ถอดและแปลเสียงทั้งฉากด้วยบริบทของเรื่อง

**ข้อกำหนดฉบับปรับปรุงสำหรับ Dub & Sub Studio**

1. ใช้ Gemini เป็นวิธีถอดเสียงเดียว ปุ่มหลักของหน้า Create แจ้งการส่งเสียง บริบท และภาษาที่เลือกไปยัง Google ก่อนเริ่มงานด้วยคลิกเดียว มีทางเลือกสร้างโปรเจกต์เปล่าสำหรับนำเข้าซับเอง การโหลดหน้าใหม่ไม่สร้างคำขอแบบเสียเงินอีก โปรเจกต์เดิมถอดใหม่และตรวจตัวอย่างก่อนแทนที่ได้
2. แปลข้อความที่แก้ไขแล้วด้วย Gemini โดยส่งข้อความและบริบทของเรื่อง เก็บเวลา cue, บทต้นฉบับ, take และภาษาอื่นไว้ รองรับทั้งประโยคที่เลือก ประโยคที่ยังขาด และการแปลทั้งแทร็ก ตรวจสิทธิ์ revision และป้องกันส่งซ้ำเช่นเดียวกับงานถอดเสียง แสดงที่มาของชุดบทที่ใช้อยู่และสถานะตัวอย่างที่ยังไม่ใช้ โดยไม่ระบุ Gemini ให้ซับเก่าที่ไม่ทราบที่มา
3. จัดซับไทยด้วยขอบเขตคำและกลุ่มอักษร รักษาบรรทัดที่ผู้ใช้กำหนด ให้พรีวิวและไฟล์วิดีโอฝังซับใช้กฎจัดบรรทัดเดียวกัน คำยาวที่จำเป็นต้องแบ่งต้องรักษาวรรณยุกต์กับอักษรฐาน ตรวจด้วยวิดีโอแนวตั้งและข้อความไทยปนภาษาต่างประเทศ
4. ขณะเล่นแบบซูม ให้หัวอ่านเดินถึงหนึ่งในสามของพื้นที่มองเห็นแล้วเลื่อนคลื่นเสียงและแถบซับต่อเนื่องตามเวลาของวิดีโอ รวมช่วงเงียบ แถวบทแสดงสถานะตามเสียง หยุดตามอัตโนมัติเมื่อผู้ใช้เลื่อนหรือแก้เวลาเอง กลับมาตามเมื่อสั่งเล่นอีกครั้ง โหมดเห็นทั้งคลิปแสดงหัวอ่านบนภาพรวม

**จดไว้สำหรับรอบถัดไป — ตรวจผู้พูดก่อนใช้ผลถอดและแปลด้วย Gemini** ในหน้าตรวจตัวอย่างให้แสดงผู้พูดในแต่ละช่วง พร้อมเวลา บทต้นฉบับ และคำแปล ถ้าระบุชื่อได้จากข้อมูลตัวละครที่มี ให้แสดงชื่อนั้น ถ้าแยกเสียงได้แต่ยังไม่ทราบชื่อ ให้ใช้ป้ายเดิมตลอดคลิป เช่น “ผู้พูด 1” และ “ผู้พูด 2” ช่วงที่ระบุผู้พูดไม่ได้ให้แสดง “ไม่แน่ใจว่าใครพูด” ให้ผู้ใช้ตรวจแล้วเลือก **ใช้ซับชุดนี้** เพื่อยืนยันผลพร้อมผู้พูด หรือ **ถอดใหม่** เพื่อขอตัวอย่างชุดใหม่ บทและไทม์ไลน์ที่ใช้อยู่จะเปลี่ยนเมื่อยืนยันผลเท่านั้น ตรวจรับด้วยบทสนทนาที่ผู้พูดสลับกันและมีอย่างน้อยหนึ่งช่วงที่ระบุผู้พูดไม่ได้

- ผู้ใช้ local admin ที่เปิดการเรียก API จริงเริ่มสร้างและถอดได้จากหน้า Create หรือเลือก **ถอดใหม่ด้วย Gemini** ใกล้รายการบทของโปรเจกต์เดิม การเปิด Editor อย่างเดียวอ่านข้อมูลที่มีอยู่
- เมื่อผู้ใช้ยืนยัน ให้แยกเสียงจากวิดีโอของโปรเจกต์ คลิปสั้นส่งเสียงครั้งเดียว คลิปยาวแบ่งช่วงตามข้อกำหนด Speech-aware transcription ด้านล่าง ทุกช่วงได้รับภาษาและบริบทเดียวกันเพื่อช่วยเลือกคำเรียก ชื่อบุคคล และระดับภาษา เก็บบทต้นฉบับพร้อมคำแปลและเวลาเริ่มและจบบนไทม์ไลน์เดิม
- ผู้ใช้ตรวจเวลา ข้อความต้นฉบับ และคำแปลได้ทุกแถวก่อนเลือกใช้หรือยกเลิก แสดงผลกระทบต่อซับภาษาอื่นและการจับคู่เทคก่อนแทนที่ แทร็กที่ล็อกและ revision ที่เปลี่ยนต้องได้รับการตรวจทั้งใน Editor และบนเซิร์ฟเวอร์
- ตรวจด้วยเสียงและผู้ให้บริการจำลอง ครอบคลุมการยืนยัน การส่งคำขอซ้ำ ขอบเขตไฟล์ และข้อมูลตอบกลับที่ผิดรูปแบบ การประเมินคุณภาพภาษาจริงใช้ฉากเดียวกันเทียบคำเฉพาะ สรรพนาม บทตกหล่น และจังหวะซับกับเสียงต้นฉบับ

โปรเจกต์เป็นเจ้าของ source media ID, revision, ภาษา, character mapping, tracks, cues และ export records แต่ละ cue มี stable ID, ช่วงเวลา, speaker, ต้นฉบับ, คำแปลแยกภาษา, บทพากย์ และ selected take ID เก็บเสียงผ่าน Voice Studio แล้วอ้าง ID ใน timeline แยกไฟล์สื่อจาก metadata ทุกการอ่าน/เขียนตรวจสิทธิ์เจ้าของที่ server ใช้ revision ตรวจการบันทึกทับจากหลายแท็บ งานระยะยาวต้องกลับมาอ่านสถานะหลัง reload และผูกคำขอซ้ำกับ operation เดิม

| งาน | เจ้าของและจุดเชื่อมต่อ |
|---|---|
| เสียง ตัวละคร และเทค | ใช้ `server/app/routes/voiceStudioRoutes.js` ผ่าน client API เดิม ได้แก่ catalog, characters, custom-voices, documents/rows, quotes, generations, selected-take, takes/save และ audio-library |
| ถอดเสียงและแปลข้อความ | `DubProjectService` ตรวจโครงการและ revision ก่อนส่งผ่าน Generation ไปยัง Gemini ใช้เสียงสำหรับถอดทั้งฉาก และใช้บทต้นฉบับพร้อมบริบทสำหรับแปลรายประโยคหรือทั้งแทร็ก |
| แปลและ export | ตรวจ service ของระบบสำหรับคู่ภาษา การสร้าง waveform, mix และ render ในขั้นทำ contract ก่อนเปิดใช้งาน แต่ละขั้นส่งสถานะ/ข้อผิดพลาดกลับระดับโปรเจกต์ แยกงานถอดต้นฉบับจากซับที่ผู้ให้บริการสร้างให้เสียงพากย์ |
| Seed Audio | เพิ่ม adapter หลัง Voice Studio generation ตามคู่มือ ผูก model/availability/credentials/ราคา ผ่าน server เช่นเดียวกับโมเดลเดิม ทุกการสร้างเสียงใช้ quote และ operation lifecycle เดิม |

## 6. JSON configuration สำหรับ frontend

ค่าหน้าจออยู่ใน [editor-config.json](../../web-next/src/features/dub-sub/editor-config.json) และตรวจ schema ที่ feature boundary ภาษา ขนาดหน้า จำนวนแถวบทบนจอ เวลา autosave ระยะ cue เริ่มต้น ระดับซูม และรูปแบบส่งออกปรับได้ที่นี่ ตัวอย่างค่าเริ่มต้นคือรายการ 20 โปรเจกต์ต่อหน้าและบันทึกหลังหยุดแก้ 1,400 มิลลิวินาที เมนู Studio ใช้ routes ของ FE24 ฟอนต์ใช้ไฟล์ OFL ชุดเดียวกับ renderer

API configuration ยึด [กระบวนการเดิม](../023-voice-studio/003-model-configuration.md) ผ่าน server catalog ที่ตรวจ schema และสิทธิ์ก่อนส่งให้ browser รายการโมเดล ภาษา ความสามารถ เพดานราคา และ availability มาจาก API ตัวเลือกที่แสดงเป็นผลร่วมของ UI config และความสามารถจริงของ API ค่าเฉพาะโปรเจกต์และเนื้อหางานบันทึกกับโปรเจกต์ Secret เก็บฝั่ง server

## 7. ลำดับส่งมอบและเกณฑ์ตรวจ

| งาน | ตรวจจบเมื่อ |
|---|---|
| 1. โครงหน้าและ config | สลับ Playground/Studio ได้ เปิดโปรเจกต์แล้วเลือกเสียงพากย์รายประโยคใน Editor ได้ เปลี่ยน page size ใน JSON แล้วรายการโหลดตามค่า |
| 2. Project และ Editor | สร้างจากวิดีโอแนวตั้ง เปิดต่อหลัง reload และเลือก cue แล้ววิดีโอ/แทร็กตามกันทั้ง desktop, tablet, mobile |
| 3. ถอดและแปล | ทดสอบคลิปจีนพร้อมคำแปลไทย แก้หนึ่งประโยคแล้วภาษาอื่นและเวลาต้นฉบับอยู่ครบ กู้คืนงานล้มเหลวได้ |
| 4. Voice และ Seed Audio | ทดสอบโมเดลเดิมและ adapter ใหม่ด้วย fixture สองตัวละคร เลือกเทค วางเสียงถูกช่วง ตรวจ overrun, duplicate submit และ timeout ระหว่างรับผล |
| 5. บันทึกและส่งออก | เปิดงานอีกครั้งแล้วได้เทคและเวลาที่เลือก SRT/VTT ตรงกับ timeline ไฟล์เสียงและวิดีโอเล่นได้ ดาวน์โหลดเฉพาะไฟล์สำเร็จตามสิทธิ์เจ้าของ |

## 8. รายละเอียดหน้าจอและแนวทางประมวลผล

- Create รับทั้ง upload จากเครื่องและเลือกสื่อเดิม แสดง progress และตรวจไฟล์ด้วย ffprobe เก็บต้นฉบับไว้สำหรับ export เลือกภาษาต้นทางหรือ Auto แยกจากภาษาเป้าหมาย ข้อเสนอสำหรับรุ่นแรกคือสูงสุด 2 ภาษาเป้าหมายต่อโปรเจกต์ ตัวอย่างต้นทางจีนและเป้าหมายไทย/อังกฤษ ค่าเพดานแสดงผ่าน configuration และตรวจซ้ำที่ server
- Editor ใช้ React/TypeScript ใน web-next, HTML video เป็นนาฬิกากลาง, Canvas วาด waveform จาก peaks ที่ worker เตรียม, Web Audio เล่นและปรับ gain ของเทคตาม playhead เดียวกัน การ seek/pause/เปลี่ยนประโยคต้องจัดเสียงให้ตรงใหม่ แยกตำแหน่งซับในภาพ (พิกัดสัดส่วนของพื้นที่วิดีโอจริง) จากเวลา cue และ offset ของคลิป WAV
- แผง Tracks ให้เปิด inspector ของภาษาที่เลือก ใช้ 2 preset ฟอนต์ คือ Sans (Noto Sans Thai + Noto Sans CJK SC) และ Serif (Noto Serif Thai + Noto Serif CJK SC) เลือก glyph ตามภาษาและ variant ที่รองรับ ใช้ไฟล์ฟอนต์เวอร์ชันเดียวกันทั้ง preview และ render ตัวเลือกสีขาวหรือเหลืองพร้อมเงาดำ ปรับขนาด ตำแหน่ง จำนวนอักขระต่อบรรทัด เปิด/ซ่อน และ reset ต่อแทร็ก รองรับเปลี่ยนอักษรจีนย่อ/เต็มโดยคงเวลา, re-transcribe, OCR ซับฝัง และ import SRT/VTT ผู้ใช้ตรวจข้อความก่อนแทนบทที่แก้มือ
- เพิ่ม inspector กำกับพากย์ของประโยค แสดงตัวละคร/เสียงหลัก ภาษาพูด บทที่จะอ่าน อารมณ์ ความเข้ม จังหวะและคำกำกับอิสระ พร้อมเวลาเป้าหมายและความยาวเทคจริง ใช้ค่าเสียงประจำตัวละครและ override ราย cue ฝั่ง server แปลงเสียงที่เข้ากันได้เป็น speaker/reference และแปลงคำกำกับเป็น text_prompt ตาม adapter เก็บ snapshot กับเทคเพื่อเทียบเวอร์ชัน ให้แก้เทคเฉพาะประโยคก่อนเลือกวางบน track
- JSON ฝั่ง frontend เก็บ preset IDs, สี เงา ขนาดตั้งต้น safe margins, UI limits และปุ่มลัด ส่วน capability จริงมาจาก API catalog ตามข้อ 6 แยก secret และ provider config ไว้หลังบ้าน
- Backend ใช้ Node/Express ประสาน project/job/Voice Studio, FFmpeg จัดการสื่อ และ Gemini สำหรับถอดและแปล การอ่านซับที่ฝังในภาพใช้ OCR เดิมของ Dub Studio
- Export เลือกเก็บ video stream เดิมแล้ว mux เสียง/ซับแยกเมื่อ container รองรับ หรือเลือกฝังซับด้วย ASS/libass ผ่าน FFmpeg ที่ความละเอียดต้นฉบับ โหมดฝังซับต้อง encode ภาพใหม่ ใช้ preset คุณภาพสูงตาม codec ต้นทาง ตรวจ rotation, display aspect, frame timestamps, color metadata และ HDR compatibility ใช้เส้นทาง preview ขั้นสุดท้ายที่เรนเดอร์เฟรมตัวอย่างด้วยฟอนต์และ renderer เดียวกับ export
- เกณฑ์รับงานเพิ่ม: ทดสอบ upload และเลือกสองภาษา, สองตัวละครใช้อารมณ์ต่างกัน, font ภาษาไทยมีสระบน/ล่างและจีนไม่มีตัวสี่เหลี่ยม, ซับสองภาษาไม่ทับกัน, เทียบ preview กับ export ของคลิปแนวตั้งและแนวนอนที่ timecode เดียวกัน ตรวจภาพและเสียงท้ายคลิปว่ายังตรงกัน ดูผลทดสอบที่ทำแล้วและขอบเขตที่ต้องตรวจด้วยคลิปงานจริงใน [คู่มือใช้งาน](011-dub-sub-operations.md)
Gemini scene preview must accept chronological recovery of complete cues returned out of order and assemble final text blocks before parsing structured output. Invalid timing must still prevent applying the preview. Record safe validation diagnostics for failed previews using only the stage and request identifier.

### Speech-aware transcription for long clips

From Dialogue, one confirmation starts automatic audio segmentation, transcription and translation. The operator supplies story context once. Detect likely speech locally, preserve quiet syllables with configurable padding on both sides, group nearby speech and omit extended silence. Keep original media offsets through each cut. Bound clip length and concurrent Gemini calls in server JSON.

Each part receives the same language, era, synopsis and available character context. Known characters are candidates. A model suggestion requires review before applying a speaker name. Uncertain speakers can remain unidentified. Present one chronological preview with editable speaker attribution. Preserve existing subtitles and casting until the operator applies the preview.

Display completed and total parts from server progress. On a known failure, retain successful parts privately for the same actor, project revision, model, language and segmentation settings. An explicit retry sends only missing parts. Duplicate submissions reuse the existing request. An uncertain provider outcome requires separate handling to avoid silently paying twice.

ค่าเริ่มต้นสำหรับคลิปยาวเกิน 45 วินาทีคือแบ่งช่วงเป้าหมาย 35 วินาที เผื่อเสียงหัวท้ายด้านละ 500 มิลลิวินาที แยกช่วงเมื่อเว้นเสียงพูดตั้งแต่ 6 วินาที และส่งพร้อมกันได้ 2 ส่วน ผู้ใช้ตรวจผลรวมและแก้ชื่อผู้พูดได้ก่อนนำไปใช้

**แผงบทสนทนาใน Editor (รอปรับ UI)** จัดหัวข้อ “บทสนทนา” และตัวเลือกภาษาให้ตรงแนว ใช้ระยะขอบและช่องไฟสม่ำเสมอ เมื่อยังไม่มีบท ให้พื้นที่ว่างแสดงข้อความสั้นว่า “ยังไม่มีบทสนทนา” พร้อมปุ่มหลัก “ถอดและแปลด้วย Gemini” ที่เห็นได้ทันที เมื่อมีบทแล้ว ให้พื้นที่หลักกับรายการประโยคและช่องค้นหา ลดน้ำหนักปุ่มถอดใหม่ และให้ประโยคที่กำลังเล่นยังโดดเด่น ตรวจทั้งสองสถานะที่ความกว้างของแผงจริง รวมถึงแผงแคบบนมือถือ
**กรณีถอดเสียงครบจำนวนคำขอ (รอปรับ UI)** ใช้กล่อง Warning ตาม [ข้อกำหนด UI กลาง](../Knowledge/ui-design-system-and-visual-language.md) ในหน้าต่างถอดเสียง ระบุขีดจำกัดตามค่าที่ระบบใช้จริง ขอบเขตที่ถึงขีดจำกัด และวิธีดำเนินการต่อ ส่วนการประมวลผลที่ล้มเหลวให้ใช้กล่อง Error ที่แยกออกจากคำอธิบายฟอร์มอย่างชัดเจน
