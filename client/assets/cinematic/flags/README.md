# Country Style Flags

Local copies of the public flag SVGs from https://flagcdn.com/{code}.svg,
downloaded 2026-09-11: th, kr, jp, cn, eu, us. FlagCDN is operated by Flagpedia
and identifies Wikimedia Commons as its vector source:
https://flagcdn.com/ and https://flagpedia.net/download/api.

Used only as decorative icons next to localized labels in Cinematic Setup.
The European flag represents the Europe storytelling preset, not a claim that
Europe is a single country or all European countries belong to the EU.
No external image requests occur during selection. Keep SVGs free of scripts,
external references and embedded user data.
